# Rovai AI v0.2.5

本次更新重点改善运行时配置、渠道登录、文件预览和长会话执行体验，并修复 Windows Pi 与多项桌面交互问题。

### 其他更新

- 【功能】**新增运行时启动设置。** 支持自定义程序路径、恢复自动检测，以及按运行时配置环境变量；修复安装或升级后检查仍使用旧查找环境的问题。
- 【交互】**模型选择更方便。** 队员管理和新手引导支持按模型名称、ID 搜索，统一模型、推理强度和权限选择器；Claude Code 改为读取真实模型列表。
- 【修复】**改善模型列表加载与配置保存。** 优先展示已有列表，减少重复检查；修复目录过期导致保存失败、仅修改权限也被阻止的问题。
- 【交互】**优化飞书与钉钉扫码连接。** 改进二维码获取、登录状态识别和会话恢复，过期或超时后支持点击刷新；账号切换与断开操作统一收进“管理连接”菜单。
- 【功能】**增强 HTML 交互预览。** 改善脚本、本地资源、页面导航和内部画布的加载，支持更大的 HTML 文件；提供源码切换、错误详情与重试，切换源码时保留页面输入和滚动状态。
- 【性能】**优化长会话执行记录的加载与切换。** 执行记录按需分页、连续追加，切换会话后复用缓存，保留阅读位置与展开状态，并恢复完成步骤摘要和最新位置跟随。
- 【交互】**执行命令与工具结果展示更清楚。** 内置操作使用对应 CLI 名称，合并重复的工具与命令记录，保留完整命令和原始输出；修复 Windows PowerShell 路径遮挡实际命令的问题。
- 【交互】**待发送消息可移回输入框编辑。** 公屏和单聊统一处理，移回时退出队列并覆盖当前输入，保留正文、附件和引用；修改后重新发送进入队尾。
- 【界面】**侧栏支持调宽和完全折叠。** 恢复时记住原宽度，统一各区域分隔线交互，并修复 macOS 折叠按钮无法点击的问题。
- 【修复】**会话导航更稳定。** 仅用户消息推进侧栏排序，队员后台发言不再让会话跳动；修复展开列表中的状态、未读和标题不刷新，并支持通过完整 Camp ID 查找会话。
- 【功能】**文件与图片附件使用更顺畅。** 本地文件、目录附件直接引用原始路径，不再复制到临时目录；修复输入框附件无法点击预览，历史图片进入可视区域后自动加载缩略图。
- 【修复】**改善运行时启动与平台体验。** 修复部分运行时在 macOS 启动失败的问题，并修复 Windows 下 Pi 无法在快速对话和项目会话中正常启动的问题。
- 【修复】**完善阅读与输入细节。** 文件预览全选限定在当前正文，消息最后一行可正常引用；统一缩放档位，优化新建会话接收人提示、新手引导顺序和初次执行反馈间距。
