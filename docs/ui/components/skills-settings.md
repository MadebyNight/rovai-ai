# Skills、工具箱与会话选择

Skills 设置与工具箱是两个独立入口，沿用 [DESIGN.md](../../../DESIGN.md) 的 Porcelain Day / Steel Night token、紧凑双栏布局和既有设置导航。来源、权限和模型投递以 [Skills Rebuild v1](../../contracts/skills-rebuild-v1.md) 为权威；本页只规定用户可见交互。

## Skills：只读原生来源

顶部选择 Runtime；列表只展示该 Runtime 在执行 Host 的用户级原生 Skill，不混入旧 Rovai Library 导入行或当前项目来源。左栏搜索名称、简介和入口路径，右栏展示说明、可复制入口路径和只读 Markdown 正文。刷新只更新候选；切换 Runtime、候选或刷新时，迟到的列表/正文响应不得覆盖当前选择。

Loading、空集合、无搜索结果、部分来源不可读、整次读取失败和正文读取失败分别给出明确状态。部分失败保留已找到的项并允许重试；正文失败保留当前 Skill 和路径。窄窗口在列表与详情间切换，并提供返回列表。来源路径是证据，不构成 Runtime 已加载或模型已读的承诺。

## 工具箱：逐队员配置

左栏固定五项工具箱，显示名称、简介和已选队员数；右栏展示完整说明与队员列表。可搜索队员姓名或角色，单个复选框即时保存。全选/取消全选只作用于当前过滤结果；保存中禁止重复提交并给出状态，失败回滚可见勾选、保留错误和当前搜索/选择，用户可再次操作。`member-studio` 升级和新队员默认开启，用户可关闭；未选择 Skill 的队员仍能正常参与协作。窄窗口从列表进入配置详情后提供返回入口。

## Camp Composer 的 `/` 候选

当前 Camp 的候选包含全队配置的工具箱项及各队员 Runtime 环境可发现的用户/项目原生 Skill。相同名称的不同来源是不同项；行内显示工具箱/用户/项目来源和相关队员。键盘上下选择、Enter 确认与显式刷新可用。部分来源不可读时保留可用候选；旧引用或暂时失效来源仍作为原消息内容保留并允许发送，状态文字说明其当前不在候选中。Picker 不声称某个 Runtime 已加载 Skill。
