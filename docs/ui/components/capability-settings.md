# MCP 设置

沿用 [DESIGN.md](../../../DESIGN.md) 的主题和控件规则。左侧列表、右侧详情；新增、导入与编辑在右侧完成。
Skills 与工具箱使用[独立合同](skills-settings.md)。

## 列表与布局

MCP 配置成功读取且为空时，仅显示“添加第一个 MCP”引导和添加配置 / 从本机导入入口，隐藏空列表、搜索和隔线。首次添加或导入保留单栏，取消返回引导，第一项保存后恢复正常双栏。读取失败必须单独显示错误与重试，不能显示为空库。

MCP 的“添加”和“导入”并列放在左侧标题行，使用相同轻量图标按钮样式；“导入”提供“从本机导入 MCP”的完整可访问名称。列表只显示已安装项目，不为新建、导入或未保存内容添加占位。

MCP 不提供启停筛选或开关；一次提交完整使用队员集合，非空启用、空集合停用。
新增与导入默认不分配队员，替换保留原分配。搜索无结果显示简短文本，读取失败提供重试。

隔线默认列表宽 320px，1600px / 2300px 视口分别为 360px / 400px；范围 240–560px，
并至少给详情保留 390px。详情最大宽度随相同断点从 1280px 扩至 1440px / 1680px，实际宽度受窗口约束。
快速松手按最终指针位置提交，CSS 缩放下按逻辑像素换算；到最小宽度即停止，不新增折叠。Escape 撤回至拖动前宽度；失焦、指针取消、丢失捕获或容器宽度变化提交最后观测位置，拖拽派生的双击不复位；页面切换丢弃过期手势，不覆盖稳定偏好；仅改变容器高度不重置拖动宽度。
隔线与会话、队员、定时任务和执行台统一为 1px `--line`；悬停或拖动时整条边界使用 `--resize-line`，不增加短握柄或厚度。
不提供悬浮左右箭头按钮框。支持拖拽、双击复位、方向键（Shift 加速）、Home/End、Enter 复位，Escape 取消
当前拖拽。宽度偏好只保存在窗口本机布局存储。内容区窄于 620px 时切换列表/详情与返回入口，
支持 200% 缩放。调整宽度和切换主题保留当前输入。切换项目、离开 MCP 或取消时清空未完成的表单，重新进入从空白表单开始，不保存草稿。

## 编辑与导入

MCP 只支持 JSON 编辑，保存复用完整 schema 校验及 digest/CAS。无效 JSON 留在编辑器内；
并发冲突不覆盖当前输入。源文件损坏时阻止写入并提供重新读取/打开修正入口，平时不显示源路径。
从本机导入在右侧扫描并选择候选，默认不选中。候选按右侧内容宽度排列：窄面板一列，
660px 起两列，1060px 起三列，随隔线调整自动换列；JSON 在候选内按需展开。
来源筛选和带 Runtime 图标的标签说明出处；UI 按 Core 的固定扫描顺序对同名候选仅展示首项，
合并不同 Runtime 标签，始终保留首项的候选 ID、内容与后端冲突判断。多来源不代表内容相同，
也不保证下次扫描仍来自此前导入的 Runtime；当前不持久化精确来源绑定，不回写来源配置。
后端按完整私有定义判断“已添加”，不能用脱敏 JSON 比较。整卡可选，内部展开、编辑和操作不切换选择；
无边框的“查看配置 / 收起配置”按需展示 JSON，并标明所采用的 Runtime。取消、重新扫描、导入集中在固定顶部。
同名不同内容必须显式选择“覆盖配置”或“另存为”。已有 env/Header 值由后端保留，疑似凭证默认掩码；
详情显式点击“显示”才通过 `mcp.servers.reveal` 读取所选 ID 在预期 digest 下的单项原值，
只保留在当前编辑会话；保存、切换项目或离开页面重新隐藏。JSON 无效时仍可隐藏整个编辑区，再次显示后继续编辑。
原值不进入列表、通用回执或事件；本地存储仍为权限收紧的 `mcp.json`，并非落盘加密。
未修改、空白占位或缺省的敏感字段保留原值，掩码不能作为真实值写回，不要求重复填写。
仅当 Core 实际启动环境无法解析引用时，在详情和相应候选内显示“待配置”、变量名称及
“受影响字段”；可先导入为停用配置，不标记为已验证可用。能解析的引用不额外提示。
不兼容引用在折叠的不可导入项内说明具体字段。已存在和不可自动导入项折叠说明；不可读来源保留具体来源与重新扫描建议，不增加聚合提示。
展开后，每项的名称、带图标的来源和状态组成独立标题行；限制原因和受影响字段在下方显示，
不可并排挤进标题。已知不兼容字段和引用使用中文说明，同一项目内相同原因合并，保留全部字段并允许换行。
队员分配位于 JSON 上方，使用约 42px 高、26px 头像的整卡按钮，网格自动换列，不提供队员搜索。
选中使用浅底、完整 1px 边框和右侧小勾，保留 `aria-pressed` 与键盘激活；不加左侧复选框、边框跳动或阴影。
JSON 随内容伸缩，从 142px 至 640px 或视口高度的 58%，不通过重挂载编辑器调整高度。
保存使用图标加“保存”的轻量按钮；红色删除和保存都在固定顶部，长内容滚动不影响操作可见性。删除弹窗绑定打开时的项目身份和配置版本；
提交中阻止重复确认或关闭，失败保持弹窗与原配置。取消、关闭、Escape 或删除成功后不额外将焦点移回入口；保留弹窗内键盘操作与焦点约束。
常规说明仅按需使用与一键新建相同的问号悬浮组件。

## 验证

运行 `pnpm test:capability-workspace` 中的 MCP 回归；按[全部配色矩阵](../qa/theme-matrix.md)补足视觉验收。
覆盖空库/读取失败、首次添加与导入、JSON 错误、CAS 保留输入、敏感值读取/隐藏、缺失引用、
迟到响应隔离、原生拖动、键盘、200% 缩放和固定顶部操作。
删除确认覆盖取消、失败重试、提交中防重复与关闭拦截、配置版本冲突；不得将旧 Skills fixture 当作当前 Skills 验收。
